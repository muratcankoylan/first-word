# Shot list

All 100 shots, in order. *In* is the first frame as minutes and seconds at 24 frames a second, and *Fr* is the length in frames. One beat is 10 frames. A note in italics at the end of a picture names the transition into that shot when it is more than a plain cut.

| Made by | Means |
| --- | --- |
| GEN | Generated video |
| SHOOT | A macro insert or still, generated. Nothing is filmed. The JSON calls it MACRO |
| ARCHIVE | Real public-domain footage or a real document. It always takes the scanline pass |
| CODE | Rendered from code: type, 3D, shaders |
| INK | Hand-drawn 2D animation |

The same list lives in `shotlist.json`, one row per shot with start frame and length. The captions, the stamps and the animatic should all be driven from that file, so a timing change is made once.
