On the First Word film, every line of on-screen text has to be readable at playing speed and understandable to someone who knows nothing about the film. Check both before delivering a cut, not after the user asks.

**Why:** between 10 and 11 November 2026 the user raised this four times in a row after watching cuts: six scenes that "did not read" (v010); "What does this scene and the writings on those scenes mean?" about the whale and the end card (v011); "they are passing so fast... slow it down a bit there so we can read those writings" about the paper strips (v012); and "we can remove the first word here. It's not adding anything" about the title on the end card (v012). Each time the fault was mine: text on screen for a third of a second, a production word ("scanlines") in a line meant for viewers, a title that meant nothing to someone who had not read the plan. They also asked for the end to be "a bit more dynamic and create buzz".

**How to apply:** run the reading-load report (`out/read_report.md`, written by the conform) and treat anything it marks "freeze-frame only" as a fault unless it is deliberate texture; for text inside generated or code-drawn shots that the report does not cover (the paper strips, the card in her hand), count the frames by hand. Read each line as a stranger would and cut any word that only makes sense from inside the production. When time is too short for the words, say so with the numbers instead of shipping it. My reading, not theirs: they like the film's writing and want more of it legible, not less of it. See [[first-word-film-project]] and [[do-not-game-the-plan]].
